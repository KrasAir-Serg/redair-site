# Исправления RedAir для Beget

- `redair-fixed-2026-10-06.zip`: полный пакет сайта с фотографиями.
- `redair-update-2026-10-06.zip`: только четыре изменённых файла и инструкция, 21 КБ.

В каждом архиве есть README-BEGET.md с порядком загрузки. Существующий
redair-private/config.php нужно сохранить на Beget; его нет в архивах.

Проверены 36 серверных и 15 браузерных сценариев. Реальные сообщения Telegram
не отправлялись. Для установки загрузите содержимое public_html и
redair-private в одноимённые папки существующего сайта на Beget.
